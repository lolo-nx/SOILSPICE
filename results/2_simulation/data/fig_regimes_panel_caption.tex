\caption{\textbf{Electrical regimes under bottom-edge soiling.} \textbf{a}, Simulated changes in maximum-power voltage and current relative to the clean module; all 800 saved states are shown. Background colours distinguish current-limited, bypass-clamped and mixed regimes. The legend identifies all four band configurations: rectangles and triangles denote band shape, with open symbols for portrait and filled symbols for landscape. \textbf{b}, Corresponding regime maps versus band transmittance $\tau_I$ and active-cell coverage $A_{\mathrm{cov}}$. Coloured frames around the single-line module names and technologies key the module colours; vertical row labels use the same four configuration symbols as a. Black contours show relative maximum-power change in percent, keyed below b; negative values indicate power loss. All classifications and power values are unchanged from the saved simulations.\label{fig:regimes}}
